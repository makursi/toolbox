# 素材投递处（inbox）

把候选图丢进这个目录就行，文件名用 `<slug>.<扩展名>`（例如 `image-converter.jpg`），丢完跟我说一声，我负责裁切、压缩、转格式，并接到 `apps/web/public/`、`apps/web/src/app/` 与代码里。**值得留的原图会提交到 `apps/web/assets/tools/<slug>/cover.<扩展名>`，然后这个目录清空。**

**这个目录下的图片不进 git**（`.gitignore` 只放行这份说明），所以毛坯、大文件、还在挑的候选都可以随便放，不用怕污染版本库。

**这里是投递口，不是档案。** 处理完就删：留在这个目录里的图既不在 git 里，也没有第二个副本，等于早就删了，只是还没执行。要留的原图走 `apps/web/assets/tools/<slug>/`：那里进 git，且与 `apps/web/public/tools/<slug>/` 同形同路径，只差一级根目录。

以后再加 Tool，仍然按下面这张表投递一张封面（没有也能上，卡片退回纯文字，不放占位图）：

| 项目   | 要求                                                                                                                                                 |
| ------ | ---------------------------------------------------------------------------------------------------------------------------------------------------- |
| 用在哪 | 首页卡片上。`meta.ts` 里的 `cover`，最终落在 `apps/web/public/tools/<slug>/cover.jpg`                                                                |
| 比例   | 按 `apps/web/docs/design/assets.md` 的裁切规则来；主体别贴边，16:9 也能用，但要够大——卡片取中间的 4:3，16:9 的图至少 1760×990，裁出的框才到 1320×990 |
| 尺寸   | 按 `apps/web/docs/design/assets.md` 里的最小尺寸投递，给得更大更稳（卡片里显示为 220×165，2 倍屏要 440×330）                                         |
| 格式   | JPG / PNG / WebP / AVIF 都行，我转成该用的那一种                                                                                                     |
| 主题   | 这个工具在做的那件事：可以是抽象图形，也可以是**真实界面截图**                                                                                       |

内容要求：**已入位的三张封面都是彩色的，这是记在 `apps/web/docs/design/assets.md` 里的知情例外**（保留原色、不做单色化、不随仓库许可再授权），所以新封面**不必**压成暖色单色，也不必去色。仍然成立的是：**不要图里的文字、logo、水印**；**不要纯白背景**（画布是 `#f7f6f3`，纯白会显出一块方形补丁）；**深色模式下也成立**（卡片在深色模式里是暖近黑，构图不能依赖"白底才好看"）；不要霓虹、玻璃拟态那类与站点语言无关的装饰。

如果你手里没有图，**我可以自己产一张**：拿真实工具页截图做封面（真实截图，不是伪造图形，不违反设计规则）。

## 三、明确**不需要**的

- **404 插画、空状态图形、占位图**：设计明确禁止（`apps/web/docs/design/assets.md`）。缺图时版面靠排版承载，不画替代图形。这一条是硬规则，不是省事。
- **中文字体**：不用你找。现状是系统回退（macOS 苹方 / Windows 雅黑 / Linux Noto）。如果要做跨平台一致，我用 `next/font` 在构建期取（和现在 Geist 的做法一致，不产生运行时第三方请求），你只需要回答"要不要"——代价是构建期多下载几 MB 字体、页面多几百 KB（子集化后）。
- **图标**（Iconify/Phosphor）：那是依赖，不是素材，不需要你提供。
