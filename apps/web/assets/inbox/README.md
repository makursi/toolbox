# 素材投递处（inbox）

把候选图丢进这个目录就行，文件名用 `<slug>.<扩展名>`（例如 `image-converter.jpg`），丢完跟我说一声，我负责裁切、压缩、转格式，并接到 `apps/web/public/` 与代码里。

**这个目录下的图片不进 git**（`.gitignore` 只放行这份说明），所以毛坯、大文件、还在挑的候选都可以随便放，不用怕污染版本库。

---

## 一、现在真正缺的：工具的封面图（1 张）

| 项目   | 要求                                                                                           |
| ------ | ---------------------------------------------------------------------------------------------- |
| 用在哪 | 首页卡片上。`meta.ts` 里的 `cover`，最终落在 `apps/web/public/tools/image-converter/cover.jpg` |
| 比例   | **4:3**（我会按 4:3 居中裁切，所以主体别贴边）                                                 |
| 尺寸   | 最小 660×495；**1320×990 或更大更好**（卡片里显示为 220×165，2 倍屏要 440×330）                |
| 格式   | JPG / PNG / WebP / AVIF 都行，我转成该用的那一种                                               |
| 主题   | 「图片格式转换」这件事本身：可以是抽象图形，也可以是**真实界面截图**                           |

内容要求（这些来自 `docs/design.md`，不是我的偏好）：

- **暖色单色**：暖白、暖灰、近黑，低饱和。
- **不要高饱和的蓝紫渐变、霓虹、玻璃拟态**：这套界面没有强调色，一张彩色图会成为整页唯一一处"别的声音"。
- **不要图里的文字、logo、水印。**
- **不要纯白背景**：画布是 `#f7f6f3`，纯白会显出一块方形的补丁。
- **深色模式下也成立**：卡片在深色模式里是暖近黑，所以构图不能依赖"白底才好看"。

如果你不打算找图，**我可以自己产这一张**：拿真实工具页截图做封面（真实截图，不是伪造图形，不违反设计规则）。你说一句"截图就行"我就做。

## 二、可选：图形标记（SVG）

站点标记已经有了：`apps/web/src/app/icon.svg`，一个 `T` 的几何字形压在 ink 方块上，由页头的 `Toolbox` 文字派生（`docs/design.md` 第九节记录了"文字 wordmark 就是 logo"这个决定）。

只有当你想换成一个**真正的图形标记**时才需要这个：给我 SVG，`viewBox="0 0 32 32"`、单色、缩到 16px 仍能辨认。位图不接受（它是 favicon，要能在任何尺寸下锐利）。

---

## 三、明确**不需要**的

- **404 插画、空状态图形、占位图**：设计明确禁止（`docs/design.md` 第九节）。缺图时版面靠排版承载，不画替代图形。这一条是硬规则，不是省事。
- **中文字体**：不用你找。现状是系统回退（macOS 苹方 / Windows 雅黑 / Linux Noto）。如果要做跨平台一致，我用 `next/font` 在构建期取（和现在 Geist 的做法一致，不产生运行时第三方请求），你只需要回答"要不要"——代价是构建期多下载几 MB 字体、页面多几百 KB（子集化后）。
- **图标**（Iconify/Phosphor）：那是依赖，不是素材，不需要你提供。
