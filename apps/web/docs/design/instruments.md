# 量具

> **管什么**：两个量具各自读什么、一次读数怎么取出来、以及它们共用的那层连接。**和它一起读**：`apps/web/docs/design/components.md`（44px 那条规则与它的例外）、`apps/web/docs/design/checklist.md`（合并前要跑的那一遍）、`docs/adr/0012-playwright-for-the-browser-gate.md`（量具与门禁的分工）、`docs/adr/0015-the-shared-connection-layer-owns-the-navigation.md`（共享连接层的边界）。

**量具（Instrument）是 `apps/web/scripts/` 里的 `node:` 脚本**：连上一个已经在跑的 Chrome，把渲染出来的页面读成数字；代码在那三个文件里，规则在本文件。判据（谁退出码 1）、每个具名 **Claim** 的名册与证伪模式的全文留给后续工作搬进来，本文件先落骨架：每节只写这个量具读什么，加一段两个量具共用的读数语义。

**不归本文件**：44px 规则归 `apps/web/docs/design/components.md`；层顺序归 `apps/web/docs/design/checklist.md`；一个 Tool 自己的规则归它的 `rules.md`；量具与门禁谁断言什么归 `docs/adr/0012-playwright-for-the-browser-gate.md`。**用法也不在这里**（命令行、以及它要的那个已经跑着的 Chrome）：那待在每个脚本的头注释里，跑的地方就是查到它的地方。

## 读数的语义

**两个量具读的是同一个渲染页面，所以「一次读数」是什么，只有一份说法。**

- **命中区域的读数从控件中心向外走**（`touch-targets.mjs`）：从控件中心一像素一像素向外走，每步问一次 `elementFromPoint`，**两侧都得答得上**才继续，哪一侧先不答就停。**一个 44px 的跨度因此读出 43**：这不是误差，44 个整像素里只有 43 个内部采样点。
- **中心取真实的那个，不取四舍五入过的那个**，所以停在分数偏移上的控件不会被报小——而两侧都要求这一点，会把半个像素的偏差放大成两三像素的表面损失（#91）。**要求两侧是故意的**：一个长大盖住邻居的靶子，会在这里读成不达标，那是同一件事失效的另一种方式。
- **走有上限。** 每侧最多 120 步，所以一个轴上的控件无论多宽，读出来都是 241——远在它存在的那个阈值之上。
- **控件先落到整像素上再量**：走出来的答案是整像素，而一行的顶端是分数（#91）。
- **算一次命中**的条件是 `elementFromPoint` 返回**这个控件本身、或者它内部的任何东西**，这是有意的。
- **横向溢出只读页面自己的 `documentElement`**：不去搜嵌套滚动容器，否则一个正当可滚动的列表会被报成缺陷。

### 两个指针分支

`touch-targets.mjs` 自 #84 起每个宽度先按桌面指针量一遍，窄的那些宽度再按手机量一遍（`hover: none`）：站点把窄屏与触屏当两件事（`apps/web/docs/design/layout.md`），触屏那一支允许把控件放大（image-converter 的拖放按钮就长到 50px），所以**窄窗口那一支才是严格的那一遍**，而手机那一支是别的检查都不看的那一遍；768 与 1024 只量桌面那支。手机**只由 `Emulation.setTouchEmulationEnabled` 来模拟**，这是量出来的而不是假定的（#130）：在那之前写的是 `setEmulatedMedia` 的 `hover` 与 `pointer`，而那两条**不在协议的可模拟清单里**，两个都发出去页面仍然报 `matchMedia('(hover: none)').matches === false`，于是没有任何一条声明真的读到过手机。

### 读数取在页面停止变化之后

一次读数取在页面上**已经停止变化**的时候（#135，2026-10-05 量到），因为导航后紧接着取的那一次不是：`.reveal` 的入场还在动、懒加载的 chunk 刚落下来、Next 的路由播报元素按自己的时间表出现，三样都会改掉读数。等的是 React 自己的 hydration 信号而不是一个 sleep，因为预渲染 HTML 里的控件看起来已经 hydration，而落在它上面的点击、丢进去的文件会被静默丢掉；「停下来了」的判据（没有运行中的 CSS 动画、`readyState === "complete"`、连续两次采样既没有资源也没有 DOM 变更到达）在共享连接层里，是 `navigate` 的第三半。

### 声明出来的东西就是被读的东西

两个量具都**按名字声明**自己必须读到什么，而不是自己去猜：`ui-fingerprint.mjs` 每页声明它必须带的 **Anchor**（`data-slot`，见 `CONTEXT.md`），`touch-targets.mjs` 每页声明它必须带着的控件名，加上按选择器声明的 carriers、panel 与扫描区域。**一条命中 0 个元素的声明就是一次失败**，抓取与比对两遍都算：什么都没命中的选择器守不住任何东西，而没有这条规则，「什么都没动」和「什么都没量」印出来是同一个词。**反过来不成立**：页面带了、但没有哪条声明点名过的 `data-slot` 仍然出现在大纲里（走一遍就能找到每一个），所以多出来的那一个是一处差异，而不是一片沉默。**声明是锚点，不是样式、也不是行为**：加不加它，画出来的东西一个像素都不变。

### 量具要的那个文件

两个量具共用同一份 fixture 理由，原话几乎逐字重复在 `touch-targets.mjs` 与 `ui-fingerprint.mjs` 里：那个文件是**仓库里已有的真实 JPEG**（`apps/web/public/tools/image-converter/cover.jpg`，Tool 自己的封面），所以不必提交一份 fixture、脚本里也不必住着一个编码器；文件**只入队，从不转换**。

## `touch-targets`

**它读什么**：真实浏览器里每一个带 `.touch-target` 的控件的**命中区域**——不是声明，声明不是命中区域。`apps/web/docs/design/components.md` 要 44px，而旧层的一个 `Button` 上，声明一直在、命中区域却是按钮自己的框，因为那个根元素用 `overflow: hidden` 把遮罩裁掉了（#29），这个脚本就是看见它的东西。它走五档宽度、两套配色，先桌面指针、窄的那些宽度再手机（#84）。命中区域之外它读的仍然都是渲染页面：页面声称必须带着的控件在不在（#81），封面生成器的画布列在不在它布局规则说的断点那一侧（#80），那一页的预览还在不在它的规则允许的短视口份额里（#90），以及页面自己的横向溢出。**它刻意不读**任何不是命中测试的东西——键盘、焦点顺序、绘制；那些留给一次性脚本和 `ui-fingerprint.mjs`（后者回答的是「有没有东西动过」，不是「够不够大」）。它守的每个属性都是一个具名 **Claim**（#98），每个 Claim 自带它的读数、谓词与它印的行。

## `ui-fingerprint`

**它读什么**：页面的结构快照，以及两份快照之间的比对。几何取的是**我们自己锚定的区域**（每个的盒子与它自己的文字），加上页面的文字、链接目标与横向溢出，再加上每一条 Anchor 的每个命中上的一份固定计算样式属性清单——布局、颜色、排版与圆角（#124，#133 把它们放回来并重新基线化）。**它读的没有任何一项属于那个正在退场的组件库**：一份读数里不出现 `mantine-*`，也不出现内容哈希过的 `m_*` 类名，因为换组件层会**从构造上**搬动其中每一个，而一个对着那个库说话的仪器，做不了「把它拿掉」这件事的安全网；大纲也因此不再印标签名，谁渲染这个元素正是要变的那个东西。它读五档宽度、两套配色，视图状态在**已经加载好的页面**上模拟，一页只导航一次而不是一个状态一次，每个视图状态给 350 ms 落定。页面可以声明**它测量的那个文件**（`fileInput`，#165）与**它要跑的那次 Batch**（`convert`，#166），因为有些区域只在那之后存在。**它刻意不读**：端到端行为（一个真文件走完真 Worker）、console 报错、键盘或指针做的任何事。它还写下一条限度，免得「一模一样」被读成「什么都不会变」：大纲读的是一份固定的属性清单，所以一个控件把一个属性换成了计算效果相同的另一个时，除非它搬动了什么，否则看不见。

## `cdp`

**它是什么**：两个量具共用的那层 Chrome DevTools Protocol 连接——附着到第一个页面 target、按 id 发命令、在那个页面里求值一个表达式，以及「浏览器还在不在」：每次导航前先探一次调试端口，浏览器没了就以一句点名端口、并给出重新启动它的命令的句子失败，而不是一个读起来像「页面从来没渲染出那个控件」的连接错误（#99）。自 #104 起它也拥有「导航成功了」：一次调用只在 React 接管了页面之后才 resolve，结果报告失败的那次导航直接抛错，而**一条响应是什么意思由一个纯函数决定**，不是在 socket 上读出来的（`cdp-response.mjs`，这一层唯一一个不用浏览器、不用 socket、不用依赖就能被 Node 单测钉住的缝）。自 #135 起它还拥有「可以量了」的第三半：**页面已经停止变化**，与 hydration 的等待放在一起，因为「可以量了」是一个属性、只有一个答案，而第二个定义正是 `docs/adr/0015-the-shared-connection-layer-owns-the-navigation.md` 否掉的选项。**它刻意不共享**的三件事是：去哪些页面、视口多大与模拟哪些媒体特性、结果怎么印——两个量具在这三件事上要的东西不同——而一个真正相同的四行 console 包装，不值一个只能拿「没什么特别」来命名的模块。**它刻意不带依赖**：`WebSocket` 与 `fetch` 从 Node 22 起就是内置，`node:` 就够；「纯 CDP 够用时量具不挣依赖」这条规矩记在 `apps/web/docs/design/log.md` 第 3 条。**它不重启浏览器**：没启动过和跑到一半没了的浏览器拿到同一句话，都不会被悄悄重新拉起来，因为一次静默重启会把一个崩掉的浏览器变成一个量出来的通过。会断言的那一半不在这里，它跑在测试运行器上，在 `apps/web/e2e/`（`docs/adr/0012-playwright-for-the-browser-gate.md`）。
