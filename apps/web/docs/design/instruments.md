# 量具

> **管什么**：两个量具各自读什么、一次读数怎么取出来、以及它们共用的那层连接。**和它一起读**：`apps/web/docs/design/components.md`（44px 那条规则与它的例外）、`apps/web/docs/design/checklist.md`（合并前要跑的那一遍）、`docs/adr/0012-playwright-for-the-browser-gate.md`（量具与门禁的分工）、`docs/adr/0015-the-shared-connection-layer-owns-the-navigation.md`（共享连接层的边界）。

**量具（Instrument）是 `apps/web/scripts/` 里的 `node:` 脚本**：连上一个已经在跑的 Chrome，把渲染出来的页面读成数字；代码在那三个文件里，规则在本文件。`touch-targets` 与 `ui-fingerprint` 两节各自写全了它读什么、一次读数怎么取、它刻意不读什么，以及退出码 1 的条件（后者不进 CI）；`cdp` 一节写全两个量具共用的那层连接；每个具名 **Claim** 自己的话（它的 `about`、它的证伪路线、它印的行）跟着名册留在脚本里。两个量具共用的读数语义在下一节。

**不归本文件**：44px 规则归 `apps/web/docs/design/components.md`；层顺序归 `apps/web/docs/design/checklist.md`；一个 Tool 自己的规则归它的 `rules.md`；量具与门禁谁断言什么归 `docs/adr/0012-playwright-for-the-browser-gate.md`。**用法也不在这里**（命令行、以及它要的那个已经跑着的 Chrome）：那待在每个脚本的头注释里，跑的地方就是查到它的地方。

## 读数的语义

**两个量具读的是同一个渲染页面，所以「一次读数」是什么，只有一份说法。**

- **命中区域的读数从控件中心向外走**（`touch-targets.mjs`）：从控件中心一像素一像素向外走，每步问一次 `elementFromPoint`，**两侧都得答得上**才继续，哪一侧先不答就停。**一个 44px 的跨度因此读出 43**：这不是误差，44 个整像素里只有 43 个内部采样点。
- **中心取真实的那个，不取四舍五入过的那个**，所以停在分数偏移上的控件不会被报小——而两侧都要求这一点，会把半个像素的偏差放大成两三像素的表面损失（#91）。**要求两侧是故意的**：一个长大盖住邻居的靶子，会在这里读成不达标，那是同一件事失效的另一种方式。
- **走有上限。** 每侧最多 120 步，所以一个轴上的控件无论多宽，读出来都是 241——远在它存在的那个阈值之上。
- **控件先落到整像素上再量**：走出来的答案是整像素，而一行的顶端是分数（#91）。
- **算一次命中**的条件是 `elementFromPoint` 返回**这个控件本身、或者它内部的任何东西**，这是有意的。
- **横向溢出只读页面自己的 `documentElement`**：不去搜嵌套滚动容器，否则一个正当可滚动的列表会被报成缺陷。

### 两个指针分支

`touch-targets.mjs` 自 #84 起每个宽度先按桌面指针量一遍，窄的那些宽度再按手机量一遍（`hover: none`）：站点把窄屏与触屏当两件事（`apps/web/docs/design/layout.md`），触屏那一支允许把控件放大（image-converter 的拖放按钮就长到 50px），所以**窄窗口那一支才是严格的那一遍**，而手机那一支是别的检查都不看的那一遍；768 与 1024 只量桌面那支。手机**只由 `Emulation.setTouchEmulationEnabled` 来模拟**，这是量出来的而不是假定的（#130）：在那之前写的是 `setEmulatedMedia` 的 `hover` 与 `pointer`，而那两条**不在协议的可模拟清单里**，两个都发出去页面仍然报 `matchMedia('(hover: none)').matches === false`，于是没有任何一条声明真的读到过手机。

### 读数取在页面停止变化之后

一次读数取在页面上**已经停止变化**的时候（#135，2026-10-05 量到），因为导航后紧接着取的那一次不是：`.reveal` 的入场还在动、懒加载的 chunk 刚落下来、Next 的路由播报元素按自己的时间表出现，三样都会改掉读数。等的是 React 自己的 hydration 信号而不是一个 sleep，因为预渲染 HTML 里的控件看起来已经 hydration，而落在它上面的点击、丢进去的文件会被静默丢掉；「停下来了」的判据（没有运行中的 CSS 动画、`readyState === "complete"`、连续两次采样既没有资源也没有 DOM 变更到达）在共享连接层里，是 `navigate` 的第三半。

### 声明出来的东西就是被读的东西

两个量具都**按名字声明**自己必须读到什么，而不是自己去猜：`ui-fingerprint.mjs` 每页声明它必须带的 **Anchor**（`data-slot`，见 `CONTEXT.md`），`touch-targets.mjs` 每页声明它必须带着的控件名，加上按选择器声明的 carriers、panel 与扫描区域。**一条命中 0 个元素的声明就是一次失败**，抓取与比对两遍都算：什么都没命中的选择器守不住任何东西，而没有这条规则，「什么都没动」和「什么都没量」印出来是同一个词。**反过来不成立**：页面带了、但没有哪条声明点名过的 `data-slot` 仍然出现在大纲里（走一遍就能找到每一个），所以多出来的那一个是一处差异，而不是一片沉默。**声明是锚点，不是样式、也不是行为**：加不加它，画出来的东西一个像素都不变。

### 量具要的那个文件

两个量具共用同一份 fixture：那个文件是**仓库里已有的真实 JPEG**（`apps/web/public/tools/image-converter/cover.jpg`，Tool 自己的封面），所以不必提交一份 fixture、脚本里也不必住着一个编码器；文件**只入队，从不转换**。

## `touch-targets`

**它读什么**：真实浏览器里每一个带 `.touch-target` 的控件的**命中区域**——不是声明，声明不是命中区域。`apps/web/docs/design/components.md` 要 44px，而旧层的一个 `Button` 上，声明一直在、命中区域却是按钮自己的框，因为那个根元素用 `overflow: hidden` 把遮罩裁掉了（#29），这个脚本就是看见它的东西。命中区域之外它读的仍然都是渲染页面：页面声称必须带着的控件在不在（#81），封面生成器的画布列在不在它布局规则说的断点那一侧（#80），那一页的预览还在不在它的规则允许的短视口份额里（#90），以及页面自己的横向溢出。**它刻意不读**任何不是命中测试的东西——键盘、焦点顺序、绘制；那些留给一次性脚本和 `ui-fingerprint.mjs`（后者回答的是「有没有东西动过」，不是「够不够大」）。

**一次读数取在哪些用例上**：四页——首页、**框架自己的 404**（#161 之前这一页在两个量具里都没有任何声明：它带页头的配色开关，加上它自己那个「回家」的控件）、image-converter 与 cover-generator——各跑五档**宽度 × 高度**（#89）：360×900、375×667、390×900、768×900、1024×900，乘浅色与深色两套配色；每个用例先按桌面指针量一遍，360 / 375 / 390 再按手机量一遍（#84，见「两个指针分支」），768 与 1024 只有桌面那一遍。900 曾经是唯一的高度，因为只有宽度被测过；**矮**屏才犯的病——封面生成器的钉住预览吃掉半个视口——在 900 上看不见，于是高度成了用例的一部分。375×667 是本人实际拿着的那台 iPhone SE：一个此前既不在宽度表里、高度更是从来没有被用过的一档。

**读数要先到那个状态**：只有丢进一个文件之后才存在的控件（第二个 Tool 的清空与行内移除叉、封面生成器的 清除）靠**页面自己收下那个文件**来达到——无头 Chrome 能设一个文件输入，手法记在 `apps/web/docs/design/log.md`；页面声明的 `fileInput`、`convert`、`layout` 与 `sections` 就是「这一页要到哪个状态才量得到」。压按钮、切分区一律发**指针序列**（`mousedown` + `mouseup` + `click`），不是一次 `click()`：新层的按钮与标签在 `mousedown` 上动作，一个只发 `click` 的程序化点击会让标签行看起来根本没有被点过（#117）。等的是**过渡**而不是一个缺失：`转换` 只在一个文件入队、目标格式在时可用，所以等它变可用、再等下载链接出现——等一个「某样东西不在了」会在 React 渲染之前就成立。一次转换就够，因为 WebP 是新页面本来选中的那个格式，一进一出；这里要的是那个状态（结果行、进度行、下载链接），编解码是门禁的事。标签行钉住那条读在**两个滚动位置**上：页面正中（预览若真钉着就在屏幕上，而一个忽略预览高度的行偏移会在那里叠上它）与页面底部——只在底部读，证明不了重叠。

**指针是从页面上读出来的，不是从这一趟的意图里推出来的**：`hover` 与 `pointer` 由平台决定，一台没有鼠标的机器回答 `none`——这条声明第一次在 CI 上跑（2026-10-05）时，每一档宽度的桌面那一遍都读到了触屏那个形状。所以 `matchMedia` 是读数的一部分，判断跟着它走：Claim 说的是「页面在它拿到的那个指针下做了什么」，而不是这个文件假定这一趟是什么意思（#130）。框的虚线与拖拽提示的 `display` 是**画出来的东西**，所以在这里直接读，不从按钮的大小去推。

**点名，不数数**：一个「至少 N 个」的下限守不住这一页——封面页一加载就可能多出约 50 行图标结果，`获取系统字体` 也带着那个类，所以「至少 4 个」在背景图与 `清除` 都还没有的时候就已经成立，而那个把文件丢进去才会出现的控件正是它漏掉的那一个（#81）。点名的每个名字在测量前都会被等到，一个从来不渲染的控件报成「缺名」，而不是安静地离开报告。**没有名字可点的控件按选择器声明**（`carriers`：每个命中都必须带着 `.touch-target`，因为那个类是这个量具唯一能看见控件的理由——丢了它，页面一个像素都不变，控件却从报告里消失，#106）；**一个分区说自己开着的时候两个方向都要读**（`presence`：本分区的面板在显示，别分区的一个都不在，#107）；**正在退场的那一层按页声明作用域**（`outgoing`）。

**`outgoing` 读的是渲染结果，不是 import**（#163）：一条死掉的 import 是一行死代码，而一个还在渲染的组件正是「每一批都搬完了」看不见的东西；类名前缀按**整个类名**匹配，库内部改个名不能让这条声明靠拼写过关。**作用域一页一页地声明**：没声明作用域的页按 `body` 处理，那是最严的读法而不是最松的；列表在搬动下一个区域的那张票里长大，在让那一页成真的那张票里长到 `body`。一条作用域命中 0 个元素就是失败——它守不住任何东西。

**它守的每个属性都是一个具名 Claim**（#98）：一个单位，自带它的读数、它的谓词和只由它印的行；`CLAIMS` 是名册，`runClaim` 是求值一条 Claim 的唯一通路，所以证伪模式重跑的是**那条**守卫而不是它的副本。每条 Claim 自己怎么变红（`falsification`：一条注入，或一条只有改源码才红的具名路线）与每条注入的清单（`FALSIFY`）跟脚本住在一起——那里写的是每条 Claim 自己的话，本文件说的是这些读数是什么。

**`--falsify` 是原地证伪**（#100、#109）：一趟绿灯之后，它按那张清单逐条破坏自己守的几何属性——一次一条，往活页面里注入一条样式，再重跑**那一条 Claim**，要求它变红；注入之后什么也没变的、注入前就已经红的、撤回之后没回到绿的，都退出码 1，因为证明不了任何东西的注入等于没证。注入可靠是因为它**无层**：无层规则压过本仓的每一层，而层顺序这条规则归 `apps/web/docs/design/checklist.md`。它也**证明不了结构或行为**：一条没被选中的面板还挂不挂着、选中的分区有没有写进 URL、键盘模型——那些是 React 的 props 与事件处理器而不是计算样式，能改它们的地方只有源码，也就是 CI（先例：把 `keepMounted` 放回去、看门禁那条新断言变红，PR #94）。它只证明它点名的那几条 Claim：报告里没被它提到的一行，这一趟不碰。注入本身另有两条写过、跑过、然后被记下来的纪律：**注入必须是同步的**——挂在带 `transition-all` 的控件上的 `transform: scale(0.5)` 会先读到旧几何、到「撤回」那一段才变红，而一个异步改页面的守卫不是一个同步读数的守卫；**改盒子也未必改到命中区域**——46px 的遮罩让 `min-height: 30px` 什么也没证明。能用的那一条是 `display`：它不能被动画，控件在 Claim 被问的时候就是没被画出来。

**退出码 1 的条件**（CI 的 `Hit areas` 一步跑的既是这一遍扫，也是 `--falsify`）：一个控件的命中区域在某条轴上低于 **43**；一个页面或一个分区说自己必须带着的控件名没有出现；一条 `carriers` 声明命中 0 个元素，或它的某个命中没有带 `.touch-target`；一个分区打开时别的分区的面板或控件还在页面上，或者本分区自己的面板没有在显示；一条 `outgoing` 作用域命中 0 个元素，或它里面还渲染着正在退场的那一层的类名；封面生成器的两列落在断点的错误一侧（#80）、那一页的预览高过它规则允许的视口份额或不再填满自己那一列（#90）、它的标签行滚走之后不再钉住（#92）；页面横向溢出；以及 `--falsify` 下某条注入没有让它的 Claim 变红，或**任何一条 Claim 声明不了自己怎么变红**——最后这一条在浏览器被叫起来**之前**就失败，而那张「每条 Claim 靠什么变红」的名册先印出来，所以「靠注入证明」从来不是猜的（#109）。

## `ui-fingerprint`

**它读什么**：页面的结构快照，以及两份快照之间的比对。几何取的是**我们自己锚定的区域**，每个带着它的盒子与它自己的文字；此外是页面的文字、链接目标与横向溢出，以及每一条 Anchor 的**每一个**命中上的一份固定计算样式属性清单——布局、颜色、排版与圆角（#124 把颜色、排版与圆角摘出去，等设计语言定稿之后由 #133 装回来并重新基线化）。大纲的每一行还带着那个元素上少数几个**决定行为的属性**（`href`、`download`、`type`、`value`、`aria-checked`、`aria-disabled`、`data-checked`）。它回答的是「有没有东西动过」，不是「够不够大」——后者是 `touch-targets.mjs` 的事。**它读的没有任何一项属于那个正在退场的组件库**：一份读数里不出现 `mantine-*`，也不出现内容哈希过的 `m_*` 类名，因为换组件层会**从构造上**搬动其中每一个，而一个对着那个库说话的仪器，做不了「把它拿掉」这件事的安全网；大纲也因此不再印标签名，谁渲染这个元素正是要变的那个东西。它读在**我们自己的锚点**上，而不是组件层拥有的类名上——这是它跨层交换之后依然成立的原因（#126 的规矩用在读数上）；锚点先铺好（#114），读数按锚点寻址（#124），并且证明过能红（#125），然后它要看的页面才允许动。

**一次读数取在哪些用例上**：四页——首页、image-converter、封面生成器，以及**框架自己的 404**（#161：这一页此前在两个量具里都没有声明，它带页头的配色开关，加上它自己那一个区域；路径故意是一个没人服务的 URL，Next 对任何未命中都渲染这一页）——各跑五档宽度（360 / 390 / 768 / 1024 / 1280）乘浅色与深色两套配色，768 以下的窗口按移动端设备度量。**视图状态在已经加载好的页面上模拟，一页只导航一次而不是一个状态一次**：一页的大纲取在固定视口（1280×900）与固定配色（浅色）上，而这两半都必须显式设置，因为视口会在一次窄窗口那一遍之后被读成一处差异、配色则会停在上一页（#105）；比对读的是两份文件里出现过的**所有**视图状态，不只看 `before` 那一份的（#105）。**每个视图状态给 350 毫秒落定**再取读数：这是这个站点从未输过的一场赛跑，而某一对配色一旦出现了别处都没有的差异，它就是第一个要被怀疑的东西。

**它读哪些锚点**：每个页面按名字声明它必须携带的 Anchor（`data-slot`，见「声明出来的东西就是被读的东西」与 `apps/web/docs/design/components.md`），名字经**一处**变成选择器，三个读数共用它——大纲的走、命中检查与计算样式读数，所以一个名字不会有两种意思。大纲只印锚定的元素，子元素多走一层，所以区域的形状留得住，而组件层在我们自己的元素之间加的那些包装（多包一层 `div`、组件自己生成的一个 `label`）不进读数；文字取自元素自己的文本节点而不是 `innerText`，因为旧库会把 `<style>` 元素内联进组件里，一份文档级的读法会把它的 CSS 当成文案。**没有哪条声明点名的 `data-slot` 仍然出现在大纲里**，所以多出来的那一个是差异，而不是一片沉默。**链接只印 `blob:` 这个 scheme 本身、不印地址**（#166）：Tool 每次加载都从刚编出来的字节现铸一个带新 UUID 的地址，比对它就是比对两个随机串，同一份构建抓两遍也会不同。

**声明命中 0 个就是失败**，而这条量具把这条规则**问两遍**：页面级一次、每个视图状态再一次——一个在 1280 在、在 360 不在的 Anchor 属于状态而不是页面。比对还多认一种失败：一份**根本没有锚点读数**的文件（它来自这条规则之前，或者被手改过）与「这一页什么都没量到」分不出来，所以它也失败，而不是读成「没有问题」。这条规则的先例是命中区域量具的 `carriers`（`touch-targets.mjs`），同一个道理。抓取会把失败印在它取读数的地方，并且**仍然写出文件**：一份失败的抓取值得和成功的那份对差。这句话只由**一处**说出来，因为一条失败写成两种说法就是两条会漂移的规则，而一次红了的运行要能 grep 到它。

**读数要先到那个状态**：页面可以声明**它测量的那个文件**（`fileInput`，#165）与**它要跑的那次 Batch**（`convert`，#166），因为有些区域只在那之后存在——第二个 Tool 的文件列表、它的结果行、进度行与失败；不然就只能在「量这些区域」与「对它们什么都不声明」之间选。文件在导航停稳之后进去，页面**再停稳一次**才取读数（#135 那条规矩，用在这一趟自己制造的那一次变化上），并且在那一页的十个视图状态里一直待着。Batch 由**页面自己那个 转换 按钮**驱动：发的是**指针序列**（`mousedown` + `mouseup` + `click`），因为新层的按钮在 `mousedown` 上动作（#117），等的是**一次转换的产物**——第一个下载链接。**等的是「在」，不是一个缺失**：等一个「不在了」会在 React 渲染之前就成立。一次转换就够，因为 WebP 是新页面本来选中的那个格式，而编解码是门禁的事。这是**覆盖面往外扩**，不是第二份「可以量了」的定义：文件与停稳这两半都是共享连接层的（`setFile`、`settle`，见下一节与 `docs/adr/0015-the-shared-connection-layer-owns-the-navigation.md`），按下去那一下是每个量具自己的——去哪些页面、把页面弄到哪个状态，正是那层故意不共享的东西。

**它刻意不读**：端到端行为（一个真文件走完真 Worker）、console 报错、键盘或指针做的任何事。也不读 `box-shadow`（本站只写一处，并且把它写成位置，归 `apps/web/docs/design/colour.md`）与任何 `::before` / `::after` 画出来的东西（本站依赖的那一个伪元素归命中区域量具）。**它还写下一条限度**，免得「一模一样」被读成「什么都不会变」：大纲读的是一份固定的属性清单，所以一个控件把一个属性换成计算效果相同的另一个时，除非它搬动了什么，否则看不见。

**退出码 1 的条件**：一次比对发现差异；一条声明命中 0 个元素，或者一份文件根本没有锚点读数——不管发生在抓取那一遍还是比对那一遍。它**不进 CI**：它的「之前」是人在同一台机器上存下的一个文件，CI 里没有可比的东西；量具与门禁的分工归 `docs/adr/0012-playwright-for-the-browser-gate.md`。

## `cdp`

**它是什么**：两个量具共用的那层 Chrome DevTools Protocol 连接——连的是**一台已经在跑的** Chrome（`apps/web/scripts/cdp.mjs`，它的响应分类在 `apps/web/scripts/cdp-response.mjs`）。附着到调试端口 `/json/list` 里**第一个 page target**，把命令按自增 `id` 发出去，按 `id` 把回答交给正在等它的那条命令（没有 `id` 的消息是事件，不是谁的回答），以及在那个页面里求值一个表达式（发过去的表达式住在模板字符串里，所以连它自己的注释里都不能出现反引号，#108）。**它拥有「浏览器还在不在」**：每次导航**之前**以 2 秒超时探一次 `/json/version`——探的是调试端口而不是这条 socket，因为 socket 是这个页面的、要问的是它背后那台浏览器还在不在——探不到就抛出**同一句话**，那句话里有三样东西：**端口**、**能原样粘进 shell 的完整启动命令**、以及「中途死掉的浏览器是失败，绝不重启」。socket 中途关掉或报错时，所有在途命令也以同一句话失败，因为那才是中途杀掉浏览器真正会命中的一条；而「没启动过」与「跑到一半没了」对要动手的人来说是同一件事，所以共用同一句话，而不是 runtime 自己那句没东西可照做的 `fetch failed`（#99）。

**启动命令的文本是故意重复的**（#99）：那条 CI 外壳、两个脚本的头部、加上故障消息里这一份，一共四处——因为**启动正是因机器而异的那部分**（CI 里起的是 `@playwright/test` 钉的那一个，人起的是这台机器上装的那个 Chrome），而一条没人能照做的失败情报不值得印。重复的是文本，不是规则：规则在这里，那段能照抄的命令留在人读到它的地方。

**它拥有「导航成功了」**（#104）：`navigate` 先探端口，再发 `Page.navigate`——**结果里带着 `errorText` 的失败是抛错，不是一条回答**，因为忽略它的调用方会去量「浏览器碰巧正在显示的东西」，那是一个没有服务器服务过的页面——然后等 React 自己接手，再等页面停止变化（第三半，见上一节）。**它还拥有「一条响应是什么意思」**：每条回答在交给调用方之前先过 `cdp-response.mjs` 的 `classify`——协议错误（一条带 `error`、没有 `result` 的回答）与「既没有 `result` 也没有 `error`」都以带**方法名**的句子拒绝；在这个函数存在之前，前一种回答被当成「值恰好缺掉的回答」，同一次失败因此被读成两次页面问题（六秒之后那句「页面从来没有水合」，和一次什么也没点名的 JSON 解析失败）。**这个分类是一个纯函数**——一条回答进、一句判决出——所以 socket 不再是决定一句话意思的地方，而这也是这一层**唯一**一个不用浏览器、不用 socket、不用依赖就能被 Node 单测钉住的缝（#104）。

**它还拥有「可以量了」的第三半**（#135，2026-10-05 量到；判据的四样见上一节）：在 hydration 之后，`navigate` 还要等到页面上不再有运行中的 CSS 动画、`readyState === "complete"`、并且**连续两次采样**既没有新的资源条目也没有新的 DOM 变更；最多 40 次 × 100ms，四秒还不静止就是一次带句子的失败——一个一直不静止的页面是缺陷，不是一次慢通过。等的是 React 自己的 hydration 信号（宿主元素上的 `__reactFiber…`，服务端 HTML 里不可能有，门禁的页面助手等的也是它）而不是一个 sleep，因为预渲染 HTML 里的控件看起来就是水合好的，点它或往里丢文件会被静默丢掉；指纹里那 1800ms 的 sleep 两个方向都错，换掉之后同一份构建连抓两遍 `ALL IDENTICAL`（#104）。**那四样不是同一种东西**（#135）：入场动画让读数落在 `Math.round` 会翻的分数偏移上，资源条目数是懒加载 chunk 到场的方式，DOM 变更计数看得见 Next 那个既不挂载东西也不发请求的 route announcer，而 `readyState` 是最便宜的那一样。**字体刻意不在其中**：一个字重换进来不会搬动量具读的那些盒子，而等 `document.fonts` 会让共享层依赖一条不归它的字体加载策略。丢进一个文件之后要再静止一次，`settle` 就是同一个 `waitForStillness`（不是副本），因为「可以量了」是一个属性、只有一个答案，而第二个定义正是 `docs/adr/0015-the-shared-connection-layer-owns-the-navigation.md` 否掉的选项。

**它还拥有把文件放进页面**（#164、#165）：`setFile(selector, path)` 按选择器找到那个 file input，用 `DOM.setFileInputFiles` 把文件设上去；**React 收得到**——input 自己的 change 事件还在，CDP 只是把文件设到它上面（无头 Chrome 做得到这件事，手法记在 `apps/web/docs/design/log.md` 第 2 条；「做不到」的说法是更早那件工具的限制）。它**不是**第二份「可以量了」的定义：丢一个文件会改页面，而等什么是调用方自己知道的事——扫那一遍按名字等它马上要量的控件，指纹用 `settle` 再静止一次。

**它刻意不共享**的三件事：**去哪些页面**、**视口多大与模拟哪些媒体特性**、**结果怎么印**——两个量具在这三件事上要的东西不同，而一个真正相同的四行 console 包装，不值一个只能拿「没什么特别」来命名的模块（#104，`docs/adr/0015-the-shared-connection-layer-owns-the-navigation.md` 的 Decision 3）。**它刻意不带依赖**：`WebSocket` 与 `fetch` 从 Node 22 起就是内置，`node:` 就够；「纯 CDP 够用时量具不挣依赖」这条规矩记在 `apps/web/docs/design/log.md` 第 3 条。**它不重启浏览器，这里和别处都不**：一次静默重启会把一个崩掉的浏览器变成一个量出来的通过。会断言的那一半不在这里，它跑在测试运行器上，在 `apps/web/e2e/`（`docs/adr/0012-playwright-for-the-browser-gate.md`）。
