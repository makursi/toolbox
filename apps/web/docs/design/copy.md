# 文案

> **管什么**：用户能读到的句子怎么写、标点怎么打、哪些词禁用。**和它一起读**：`apps/web/docs/design/typography.md`（中文逐字回退到系统字体）。

- **用户能读到的地方，零 `—`（em dash）、零 `–`（en dash）**：标题、正文、按钮、alt 文本、错误提示，全部算在内。这条来自门禁协议，并且是**对着预渲染出的 HTML 检查**的，不靠眼睛看。代码注释与仓库文档不算“用户可见”，保留仓库自己的文风。
  **中文同样适用**：中文的 `——`（破折号）是同一个 AI 味的重灾区，改用逗号、分号或冒号。
- **中文排版约定**：标点用全角（`，。：；？！`）并配中文引号；**格式缩写（PNG / JPEG / WebP / AVIF / BMP）与项目名（Toolbox）保留拉丁写法**，这是中文技术界面的普遍做法；`<title>` 的模板分隔符用 `|` 而不是中点 `·`（中点本身就是要节约使用的东西）。
- 用平实、具体的语言。禁用："Elevate"、"Seamless"、"Unleash"、"Next-Gen"、"Game-changer"、"Delve"。
- 不编造数据、不用占位人名、不写假精确的数字。
- **同一个承诺在一页里只说一次。** 工具页曾经同时用两句小字（标题下的“全部在浏览器本地完成”与拖拽区下的“文件不会上传”）说同一件事，格式清单也列了两遍。现在的分工：`meta.ts` 的 description 只讲**能力**（它同时是首页卡片与分享卡片的文案），承诺写在**动作点**（添加文件那里），页脚那句是站点级的、每页一次。
- 不用 emoji、不用编号式眉标（`01 / Index`）、目前也不用任何眉标。
- 不用装饰性状态圆点、不用中点 `·` 堆元数据、不加滚动提示、不加版本号标签。
