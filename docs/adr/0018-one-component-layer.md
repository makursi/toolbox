# One component layer, and the design language is the site's own

This supersedes [ADR-0016](0016-the-component-layer-is-shadcn-ui-again.md). That decision moved one page onto a vendored layer and called the result a stage with an exit condition: the old layer off the pilot page, the Instruments re-derived onto the new one, and a successor written when the design language settled. All three have happened, and the successor is this file. What ADR-0016 decided — that a vendored layer is the layer, that the registry is reached by a generator rather than by hand, and that ADR-0007's aesthetic conclusions were re-opened while its enforced ones were not — is unchanged. What ends here is the _state_: there is one component layer, and it is everywhere.

**The exit condition was read, not inferred.** The Instruments were re-pointed page by page before each page moved, and the reading that closes the round is `touch-targets.mjs`'s `no-outgoing-layer` claim: every page declares the regions it claims, every one of the four pages now claims its whole document, and the count of the outgoing library's class names on every rendered page is zero. That claim is still in the registry and still looks for the library's prefix — a reintroduction would be caught on the rendered page rather than in a manifest. The dependency itself left in #168, with a clean install (`node_modules` deleted, `pnpm install` from the lockfile) and a build with no unresolved import.

**The language, as settled.** A **Primitive** is generated into `apps/web/src/components/ui/`, is owned by the generator, and is not hand-edited; an icon the registry imports from a package this site does not have is replaced by this site's own Phosphor literal (recorded in the file), and a Primitive that turns out to be the wrong tool for a job is not used at all — the format row's stretched `<label for>` and the file input behind a real `<button>` are the two places where a native element is the answer, and each says why in place. Everything else is this site's own utilities and its own anchors: `data-slot` names a region for the Instruments, `data-layer="primitive"` marks a region where Tailwind's `white` and `black` re-point at this site's paper and ink, and `globals.css` holds the document's typography, the layer order, and the handful of rules that are geometry rather than decoration. The tokens live in one plain module, emitted as custom properties before the first paint; the colour scheme has one owner, and it is this site (`docs/adr/0017-the-site-owns-the-colour-scheme.md`).

**What was measured, and what that measurement is for.** The design language was re-derived in #116 and re-measured rather than re-picked: the palette's every value, its contrast against the surface it actually sits on, the type scale and the two radii. Each page then moved with a before-and-after fingerprint of the whole rendered page — geometry, computed colour, typography and radius, the page's text, its links and its horizontal overflow — across five widths and both colour schemes, with every difference itemized in the commit that caused it. Two of the six moves came back `ALL IDENTICAL`; the others' differences are enumerable and each is either the incoming layer naming a component it renders (`data-slot="button"`, `checkbox`, `progress`) or a correction where the outgoing layer's own value contradicted a rule this repository had already written down (its cool grey in place of the warm hairline; its pure white on a filled button's label; its borrowed pale red behind an error box). **That is what "a move rather than a redesign" means here**: a claim with a reading behind it, not a promise.

## Consequences

- `docs/adr/0016-the-component-layer-is-shadcn-ui-again.md` gains a superseded pointer. Its reasoning about the registry, the generator and the instruments stays where it is.
- **A second design system is rejected as a destination and is no longer available as a state.** The two-layer state existed for the length of one round because the pilot proved it could be bounded; it has no successor, and "keep the old library installed but unused" is not a state either — an unused dependency is a false statement about what the App is.
- **The machine-local registry wrapper is no longer load-bearing for the site.** The layer is vendored in the repository, so the wrapper's disappearance no longer threatens what runs; it threatens the next `shadcn add`, and that is the whole of what it still decides. ADR-0016 called its existence a condition of the decision, and it was — of the decision to _move_, which is done.
- **The Instruments are the migration's lasting product.** They were written to survive the swap — anchors instead of library classes, declarations instead of assumptions, and a falsification path for every claim — and they now measure a site with one layer. The next structural change is measured by them rather than argued about.
- Adding a Tool means adding a page to a site that has one vocabulary: `apps/web/docs/adding-a-tool.md` states it, and the design doc set behind `apps/web/docs/design.md` is what the page has to look like.

## Considered Options

- **Stay in the two-layer state.** Rejected: it was bounded by construction, and every change in it carried a question the code could not answer — is this difference intended, or is it the second layer leaking?
- **Move the whole site in one commit now that the registry is reachable.** Rejected for the reason ADR-0016 gives and this round confirmed: the couplings run through tokens, the scheme, the Instruments and the measured language, and a site-wide swap makes "which difference was intended" unanswerable. The per-page accounts are what made the round reviewable.
- **Keep the outgoing library installed but unused, so a rollback stays cheap.** Rejected: it would keep a second vocabulary in the lockfile and in every reader's head, and the round's own evidence is that the swap moves nothing — there is nothing to roll back to.
- **Re-open the aesthetic questions now that the layer is settled.** Rejected: they were re-derived and measured in #116 and re-measured through six page moves. Re-opening them here would re-litigate a decision this round spent its evidence on, and the ADR that settles a language is not the place to change it.
