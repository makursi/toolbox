### W. 包装器：可用，但有六处瑕疵（需求 2 的答案）

**已实测可用**：`shadcn.cmd --version` → `4.21.1`（退出 0）；`shadcn.cmd view button` → 返回真实 `new-york-v4/ui/button.tsx` 注册表条目（退出 0）。**ADR-0006 的首要前提「`ui.shadcn.com` 不可达」在事实上作废。**

前提逐条核实：Node **v24.18.0** ✓（`NODE_USE_ENV_PROXY` 需要 ≥24）；代理 **127.0.0.1:11888 正在监听** ✓；真实 shim 存在于 `%USERPROFILE%\AppData\Local\pnpm\bin\` ✓；`sh` 版 **0 个 CR 字节** ✓。

**没写错的地方**（记下来，免得修的时候改坏）：退出码传播用 `ENDLOCAL & EXIT /B %SHADCN_RC%`，依赖 `%VAR%` 解析期展开，是唯一正确的写法；`NO_PROXY` 正确把 localhost 排除；`SETLOCAL` 让环境不外泄。

**结论**：换组件层，前后两次读数**按定义必然不同**——指纹不能当这次改动的安全网。它必须先被解耦（#114 → #124 → #125），否则你会用一个正在改动的量具去量一次大改动。

### 形状：这是一次**宽重构**，不是一串功能

换组件层是一个机械改动，爆炸半径横扫每一个 UI 文件，所以单次编辑不可能绿着落地。规定动作是 **expand → 分批迁移 → contract**：

- **expand**：#112–#127（新层在旧层旁边立起来，旧层一个字不动）
- **分批迁移**：#117/#128/#129/#130/#131，**批次单位就是页面的三个分区**（内容 / 样式 / 导出，面板类 `.cover-panel-*`，量具本来就按分区声明）
- **contract**：#132（旧层从该页退场）、#133（指纹恢复完整比对）、#119（收口）

**分批单位是看代码得来的，不是猜的**：`CoverGenerator.tsx:90-434` 是 `Tabs` + 三个 `Tabs.Panel`，量具的 `PAGES.cover.sections` 正好三个条目。

## 3. 不改变的东西（保护区）

任何处置如果让下列之一退化，就不如不做：

- **六条不变量里保留下来的部分**：禁纯 `#000000` 与纯 `#ffffff`；可点控件命中区 ≥44px；一切资源自本站（CSP `font-src 'self'` / `img-src 'self' blob: data:`）；图标只用 Phosphor、构建期编进 CSS、写**字面量**类名；不编造图形与数据；用户能读到的文案零 `—` 与 `——`、标点全角。
- **`touch-targets.mjs` 的规则面**：阈值 43 与「44px 跨度在探针分辨率下就是 43」的理由；case / pointer / 配色三张矩阵；`.touch-target` 只能挂在**拥有点击的元素**上；丢了类就是丢了整个靶子；单求值路径与 `--falsify` 的无层注入技巧；**#109 立下的覆盖率断言**（每条 claim 必须声明自己怎么红）。
- **ADR-0012 的两层分工**：量具测量（`scripts/`，几何）、门禁断言（`e2e/`，行为）。
- **ADR-0005 的无出网承诺**，以及 `e2e/no-outbound-requests.spec.ts` 对它的断言。
- **`@layer` 顺序本身的理由**：即使 `mantine` 层消失，顺序声明仍要给 Tailwind 工具类留出可覆盖的位置。
- **两套配色都必须补齐才能上线**；明暗切换的**可访问名由样式表切、不由 JS 状态切**（理由与实现无关，仍然成立）。
- **Tool 的私有实现与 `core/` 单测**：两个 Tool 的 `core/`、`worker/`、状态模型完全不进本轮（试点页只换界面层）。
- **`presence` 的语义**：一个分区「自己的面板在显示、别人的不在」这条要能在新层上继续被读到——这是 #117 的真风险点，因为它今天是靠旧库**内联写 `display:none`** 实现的。

**明确交给新设计语言的（重定，不是放弃）**：无强调色；暖单色；容器 8px / 控件 4px 的圆角体系；「没有阴影是设计本身」；`minimalist-ui` 与 `design-taste-frontend` 两套 skill 协议的从属关系。

## 8. 更正记录（这一轮发出去又收回的东西）

留在这里是因为「一份说谎的设计文档比没有更糟」，而**发错的票也是同一类东西**。

1. **#117 ↔ #118 曾是环。** 早先八张票里，#117（试点页搬新层）的验收要求「该页量具全绿」，而把该页声明改名正是 #118 的活，且 #118 阻塞于 #117。**#117 永远无法通过，#118 永远无法开始。** 改法：不设「检查再推导」独立票，**每个分区批次的验收里包含它自己那份声明的重新推导**（#117/#128/#129/#130/#131），页面级那部分归 #132。
2. **#118 里有一条判据是假的。** 它要求重新推导「Gate 读勾选态的断言」，理由是旧库的 Checkbox 写了那个属性。查证结果：`data-checked={enabled[format] || undefined}` 写在 `ImageConverter.tsx:225`，是**我们自己的代码**写的；而且它在 image-converter 上，本轮明确不碰。**不修**（见 I4）。
3. **形状错了：把它当成一串功能，而不是一次宽重构。** 于是「在旧库旁边把新层立起来」这一步缺失，而分批的单位（三个分区）本来就在代码里。改法：expand → 按分区分批 → contract。
4. **分支决定被事实推翻。** 早先定「叠在 `fix/instrument-trustworthiness` 上」是因为 `main` 上还没有可信量具；两条 PR 合并后该理由消失，改为**从 `main` 起**。
